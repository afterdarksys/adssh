Implement `createLoadAgent(env starlark.StringDict) *starlark.Builtin`:
- Return `starlark.NewBuiltin("load_agent", func(thread *starlark.Thread, b *starlark.Builtin, args starlark.Tuple, kwargs []starlark.Tuple) (starlark.Value, error) { ... })`.
- UnpackArgs with kwarg name `"name"` and target `var name string`.
- **Path traversal validation** (per security requirement): Check `strings.Contains(name, "/") || strings.Contains(name, "..")` → return `starlark.None, fmt.Errorf("invalid agent name: must not contain path separators")`.

- Parse: `fm, systemPrompt, err := parseAgentFile(string(data))`.
- API key: `apiKey := os.Getenv("ANTHROPIC_API_KEY")` → if empty return `starlark.None, fmt.Errorf("ANTHROPIC_API_KEY not set")`. **Never log or include the API key value in error messages.**
- Model resolution: `model := os.Getenv("ADSSHA_MODEL")` → if empty use `fm.Model` → if still empty default to `"claude-sonnet-4-6"` (per D-04).
- Create client: `client := anthropic.NewClient(option.WithAPIKey(apiKey))`.
- Initialize empty history: `history := []anthropic.MessageParam{}`.
- Return inner callable via closure: `starlark.NewBuiltin("agent", func(...) { ... })`.

The inner callable (the `"agent"` builtin returned from `load_agent`):
- UnpackArgs with kwarg name `"task"` and target `var task string`.
- Append user message: `history = append(history, anthropic.NewUserMessage(anthropic.NewTextBlock(task)))` (per D-02 — stateful history).
- Call API:
  ```go
  resp, err := client.Messages.New(context.Background(), anthropic.MessageNewParams{
      MaxTokens: 4096,
      Model:     anthropic.Model(model),
      System:    []anthropic.TextBlockParam{{Text: systemPrompt}},
  ```

- On error: return `nil, fmt.Errorf("agent API error: %v", err)`.

- Append response to history: `history = append(history, resp.ToParam())` (per D-02 — maintains multi-turn context).
- Return `starlark.String(text), nil` (per D-03 — plain Starlark string).

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Starlark session -> agent name arg | User-supplied name used to construct filesystem path — path traversal risk |
| Agent file -> system prompt | User-controlled markdown becomes Claude system prompt — prompt injection surface |
| Go process -> Anthropic API | ANTHROPIC_API_KEY sent over HTTPS — must not be logged or leaked in errors |
| Starlark session -> conversation history | In-memory history grows unbounded per session — DoS risk |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-03 | Tampering | createLoadAgent name arg | mitigate | Validate `name` contains no `/` or `..` before `filepath.Join` — reject with error "must not contain path separators" |
| T-04-04 | Information Disclosure | ANTHROPIC_API_KEY | mitigate | Read from `os.Getenv` only; never include key value in error messages or log output; error says "ANTHROPIC_API_KEY not set" not the value |
| T-04-05 | Tampering | agents/*.md system prompt | accept | Agent files are in user's home directory (~/.adssh/agents/); user controls their own prompts. Prompt injection via task argument is out of scope for v1 — Rego enforces at the MCP layer. |
| T-04-06 | Denial of Service | conversation history | accept | History is in-memory, scoped to Starlark session lifetime. Sessions are bounded by SSH connection or interactive REPL duration. Acceptable for v1 — no server-wide resource exhaustion. |
| T-04-07 | Elevation of Privilege | sys.load_agent in restricted mode | accept | Follows `load_plugin` precedent (unconditional, not behind `!restricted` gate). Agent API calls go through Claude, which uses MCP tools that ARE policy-gated by Rego. The agent callable itself doesn't bypass policy. |
</threat_model>

2. After `LogCommand("BASH", cmd)` (line 18) and before the `// 1. Check for custom Starlark Commands` comment (line 20), insert the policy evaluation block:

```go
            // 0. Rego policy evaluation (primary authorization)
            pctx := BuildPolicyContext(args[0], args[1:], "")
            allowed, reason, policyErr := EvaluatePolicy(pctx)
            if policyErr != nil {
                return fmt.Errorf("adssh: policy evaluation error: %v", policyErr)
            }
            if !allowed {
                LogPolicyDecision(pctx.User, cmd, false, reason)
                if reason != "" {
                    return fmt.Errorf("adssh: access denied: %s", reason)
                }
                return fmt.Errorf("adssh: access denied for '%s' by policy", args[0])
            }
            LogPolicyDecision(pctx.User, cmd, true, "")
```

3. Remove the two `IsAuthorized` calls (lines 26 and 51 in the original). Since Rego is now the primary authorization, the YAML entitlements check is no longer needed in the interceptor. The `IsAuthorized` function remains exported in `entitlements.go` for backward compatibility but is no longer called from the interceptor.

The final flow becomes:
- LogCommand (audit the attempt)
- EvaluatePolicy (Rego check — deny returns error immediately)
- LogPolicyDecision (audit the result)
- Custom Starlark commands (no more IsAuthorized gate)
- Virtual binaries (no more IsAuthorized gate)
- Restricted mode checks
- next(ctx, args)

Note: The `os/user` import should NOT be added to interceptor.go — BuildPolicyContext handles user lookup internally. The only imports needed are those already present.
